# 🧩 Speed Cube Time

**Speed Cube Time** é um cronômetro online para praticar e registrar tempos de resolução de cubo mágico, ideal para quem pratica *speedcubing*. Com interface simples e intuitiva, o tempo é iniciado e parado com um clique ou teclado, e você pode acompanhar seu histórico de solves e estatísticas básicas. 🚀

🔗 Acesse ao vivo: https://speed-cube-time.vercel.app/

---

## 📝 Funcionalidades

- ⏱️ **Cronômetro de alta precisão**
- 📊 **Histórico de tempos**
- 📈 Estatísticas como melhores tempos e médias
- 🔁 Possibilidade de registrar várias resoluções
- 🎨 Interface responsiva e leve

---

## 🚀 Como usar

1. Abra a aplicação no navegador.
2. Pressione Espaço ou clique no celular para iniciar o cronômetro.
3. Resolva o cubo mágico.
4. Pare o timer ao finalizar a resolução.
5. Visualize seus tempos e estatísticas.
